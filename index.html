Manufacturing platform · In development

Quatrion

Coding agents · Python → C++/CUDA · Spatial tokenization · CAD · FEA · CFD

Quatrion on GitHub ↗

I’m building an agentic platform for manufacturing companies, connecting natural-language requests to CAD and simulation services.

  • Agent-directed solver refactoring. Directed coding agents to refactor a Python FEA solver into C++/CUDA for NVIDIA GPUs, using knowledge-graph grounding and multi-agent debate to guide implementation.
  • Spatial tokenization and grounding. Built bounded knowledge graphs linking CAD parts, assembly hierarchy, 3D positions, orientations, and surface-distance relationships. These give LLMs structured spatial context, with bounded views and source provenance.
  • Custom FEA solvers. FEniCSx and PETSc solvers for linear and nonlinear structural analysis, including large deformation, J2 plasticity, GPU-accelerated sparse solves, and analytical benchmark tests.
  • CFD and forming workflows. CFD case validation and postprocessing, plus sheet-metal forming through OpenRadioss integration, asynchronous jobs, and solver-output KPI extraction.
  • Agent and deployment workflows. Structured tool calling, configurable model providers, reusable Codex and Claude Code skills, and Kubernetes/Helm deployment automation for cloud and on-premises targets, with authentication gates and CI checks for service contracts and infrastructure.
